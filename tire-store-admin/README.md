# پنل ادمین فروشگاه تایر (React + Vite + TS)

```powershell
cd tire-store-admin
npm install
npm run dev   # http://localhost:5173
```
بک‌اند باید روی `http://localhost:5188` باشد (`VITE_API_URL` در `.env` قابل تغییر؛ نمونه: `.env.example`).

- در Development، سفارش‌های نمونه و گردش خرید برای بررسی رابط باقی می‌مانند؛ در Production انتشار فعلی کاتالوگ‌محور است و هیچ سفارش نمونه‌ای نمایش داده نمی‌شود.
- صفحه سفارش‌ها و گردش اعتبار/پرداخت در Production تا تکمیل احراز هویت ERP و persistence مالی ارائه نمی‌شوند؛ خلاصه داشبورد این محدودیت را نشان می‌دهد.
- محصولات: واقعی (افزودن/ویرایش/حذف، جستجو، صفحه‌بندی، چندتصویره)
- ورود مستقل فروشگاه: نام کاربری/رمز؛ رمز موقت کاربر جدید در اولین ورود باید عوض شود
- دسترسی مدیر کل: ساخت/ویرایش/فعال‌سازی فروشگاه‌ها و ساخت/غیرفعال‌سازی کاربران فروشگاهی
- مدیریت محصول و سفارش به فروشگاه انتخاب‌شده محدود است؛ API دسترسی‌ها را سمت سرور بررسی می‌کند
- طراحی مبنا: `panel-foroushande-v2.html`
